自动化发布 Skill

按平台沉淀的自动化发布能力：上传、定时、原创声明与状态回读全自动完成。当前已上线视频号，更多平台正在开发。

这个发布 Skill 替你省掉什么

发布不再是「打开网页 → 手填字段 → 守到成功」的重复劳动。一次接入，之后每条成片自动完成上传、字段落定、定时发表与状态核验，你只需要确认选题与排期。

—已自动发布成片

定时自动发表

按排期自动上传发表，无需守在电脑前；支持改期与预演（dry-run）。

字段一次落定

短标题 16 字限制、合集归属、原创声明、完整封面帧自动处理，不发半套字段。

状态自动核验

发布后回读列表核验，审核中不误判为已发布；失败与异常自动标出并回流看板。

publish-wechat-channels

把本地已渲染成片自动发布到微信视频号助手：发表 / 草稿 / 定时 / 状态回读。

已上线

能力清单

  • 成片自动上传（真实 Chrome + CDP 接管，微信快捷登录秒回）
  • 完整封面帧自动生成，避免默认首帧暗场
  • 短标题 / 描述 / 话题 / 合集 / 原创声明 / 位置一次落定
  • 定时发表：schedule_publish.py 支持排期、改期、预演
  • 发布状态回读核验（published / platform_pending / needs_human）

关键规则

  • 单线操作锁：同一时刻只跑一个发布会话，不与定时任务抢页面
  • 所有成片一律声明原创；搬运 / 混剪场景先停下问用户
  • 合集按栏目判定：《刚哥聊 AI》→ 刚哥聊AI；快播资讯 → 科技前沿
  • 状态写回 platform.db，任务看板实时可见
