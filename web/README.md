# web/ — 自媒体数字员工平台（单入口）

`web/` 把「模板总览」「任务看板（发布看板）」「自动发布」三个原本分离的项目整合为一个平台，单入口 `http://127.0.0.1:8610/` 即可查看全链路：模板库、生成任务与发布记录、发布流水线。

| 文件 | 说明 |
| --- | --- |
| `index.html` | 平台页面（自包含单文件，四个视图：主页 / 模板总览 / 任务看板 / 自动发布） |
| `serve.py` | 平台本地服务（Python 3 标准库；`/api/*`、`/projects/*` 反向代理到任务服务） |

## 四个视图

1. **主页（默认进入）**：项目介绍 + 平台能力 + 五步工作流 + 真实统计（收录模板 / 已发布成片 / 平台审核中 / 接入平台）。
2. **模板总览**：5 套模板卡片栅格，画幅 / 类型筛选、关键词搜索、对比表、样片灯箱播放。
3. **任务看板**：生成后的视频发布看板——状态统计（待发布 / 发布中 / 平台审核中 / 已发布…）、近 7 日发布趋势、按日期分组的任务卡片（封面、状态、话题、时长、成片路径），点击卡片播放成片，支持搜索。
4. **自动发布**：发布流水线 7 步 + 两条生产约束 + 平台接入 + 最近发布记录表。

## 两条生产约束（在产品内体现）

- **产出目录固定**：制作完成的视频统一写入 `uni-ai-video-productions/projects/<工程>/deliver/`，不散落在其他位置。
- **模板源码只读**：制作过程中不得修改模板源码；确有特殊需求时，先复制工程到产出目录再调整。

## 启动方式

需要两个服务：

```sh
# 1) 任务服务（平台数据上游，数据正本 platform.db）
#    原默认端口 8899 当前被其它演示占用，这里用 8898 启动：
cd /Users/wrg/Important/uni-ai-video-productions
nohup python3 pipeline/serve.py 8898 > /tmp/uni-pipeline.log 2>&1 &

# 2) 平台服务（单入口）
cd /Users/wrg/Important/uni-ai-video-templates
python3 web/serve.py --pipeline http://127.0.0.1:8898
```

浏览器访问 http://127.0.0.1:8610/ （加 `--no-open` 不自动打开；`--port` 可换端口）。

> 任务服务换回 8899 时，平台服务相应改为 `python3 web/serve.py --pipeline http://127.0.0.1:8899`。

## 数据链路

- 平台页 `index.html` 通过相对路径 `/api/stats`、`/api/records`、`/projects/...` 取数；
- `web/serve.py` 把这些路径反向代理到任务服务（默认 `127.0.0.1:8898`），媒体带 Range（成片可拖动播放）；
- 任务服务（`uni-ai-video-productions/pipeline/`）从 `platform.db` 读真实数据，与 CLI / 定时任务共用同一把 flock。

## 新增模板时如何更新

在仓库根目录按 `TEMPLATE-STANDARD.md` 建好模板目录后，编辑 `web/index.html` 底部 `TEMPLATES` 数组，追加一条记录（字段见数组内注释），保存刷新即可。字段均取自各模板 README。

## 已知说明

- 样片 MP4 与部分字体由 Git LFS 管理；本地未检出（文件只有一百多字节的指针）时先执行 `git lfs pull`。
- 模板预览图 / 样片 / README 按仓库相对路径提供；任务成片 / 封面按 `/projects/...` 由代理转发。
