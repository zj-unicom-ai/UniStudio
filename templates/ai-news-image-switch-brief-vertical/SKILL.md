# AI 资讯图片快报（无旁白）

这个包同时包含 Skill 和可运行的 HyperFrames 工程。使用者下载或安装整个模板目录后，即可复用其中的页面、动效、示例图片、背景和配乐；不依赖分享者电脑上的路径、VoiceStudio、声线或私有工程。

## 制作流程

1. 确认用户提供的新闻稿、来源、素材或主题。整理一条资讯的标题、短副标题、事实摘要和 1–8 张相关图片。涉及近期事实时核对原始来源并记录在 SOURCES.md；无法打开来源就要求提供正文或材料，不补造事实。
2. 阅读 README.md、USAGE.md、TOOLS.md 和 SOURCES.md。用随包工程工作，保留 9:16 全息背景、信息布局、中央图片快切和 BGM-only 声音设计。
3. 确定本 Skill 安装目录（即本 SKILL.md 所在目录），从该目录调用 scripts/new_project.py 创建工程；不要依赖当前工作目录或作者电脑上的绝对路径。目标路径需不存在，例如 /path/to/new-project。此命令拒绝覆盖已存在目录，并忽略输出与缓存。进入新项目目录后再编辑数据。
4. 替换 data/sample-episode.json 中的 title、subtitle、footerKicker、footerLines、images 和 beats。把新素材复制到 assets/images/；所有路径必须是工程内的相对路径。标题、摘要长度和节拍范围由构建脚本检查。替换配乐时同时更新 bgmDuration，并确认有权使用和分享新音频。
5. 执行 npm run build 与 npm run check。用 npm run dev 预览中央图片裁切、标题可读性、图片切换节奏和 BGM 循环，再停止预览服务。
6. 渲染交付时运行 npm run render -- --quality high --output out/<name>.mp4。命令生成 MP4、完整首页封面 PNG 和带 poster 的播放页 HTML。默认封面取视频 0.5 秒，画幅为 1080×1920。
7. 检查封面、至少一处图片切换和结尾画面；用 ffprobe 核实分辨率、帧率、时长和音轨。因为该模板没有口播，不要把 BGM 称为旁白，也不要自行添加 TTS。交付 MP4、封面 PNG、播放页和工程目录，并列出来源及授权条件。

## 内容与版式边界

- 这是单条资讯快报，不是多条新闻合集或深度口播。
- 标题最多 12 个字符，副标题最多 16 个字符，底部摘要 1–3 行且每行不超过 21 个字符；写作建议与计数规则见 USAGE.md。
- 图片只在中央框切换；背景、标题和摘要保持稳定。图片按主体需要居中裁切，避免把关键文字放在画面边缘。
- 图片动效顺序由固定 transitionSeed 决定，重复构建应保持一致。不要加入随机值、渲染时网络请求或影响可 seek 时间线的动画。
- 样例背景、BGM 和照片有各自的来源与许可边界。公开发布前依据 SOURCES.md 清理未获分发许可的素材；保留出处不等于获得许可。仓库源码 MIT 不覆盖媒体资产。

工程结构、替换字段和本地依赖分别见 README.md、USAGE.md 与 TOOLS.md。
