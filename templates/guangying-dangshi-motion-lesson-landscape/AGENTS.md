# Codex 任务书 · 必须读（使用中文沟通）

> **EP01 M6 视觉重制（2026-10-14 用户要求）**：本版不调用或依赖 `huashu-art-motion` skill 来设计插画；全片视觉在 HyperFrames 合成内用内容对应的 SVG 场景完成。保留 M4/M5 工程和成片。此条仅覆盖 EP01 M6，优先于下方双引擎流程中要求 Huashu 的条款。

## 用户确认过的优先要求

1. 制作党课 **20 分钟目标**，主题《从石库门到遵义：在探索中寻找中国革命的道路》。
2. **拒绝大量静态插画 + 镜头缩放做视频**；优先使用源代码动画（Canvas/SVG）、历史资料的动态解读和结构图。
3. **必须结合** `heygen-com/hyperframes`（最终总编排/导出）和 `alchaincyf/huashu-art-motion`（动态解释短镜头）。不要说“已经直接插件化”；采用 **渲 MP4 后回填 HF 视频轨**，可升级为更深集成，但先交付可用。
4. 全片风格统一，赤金、墨黑、档案米白；不使用卡通 Q 版角色、不用紫蓝科技渐变；史实必须准确、证据可追溯。
5. 项目要能逐镜审阅、逐章渲染、替换旁白、复用模板做下一期。

## 你拿到什么

`src/graphics.js` 是逐帧寻址的 Canvas 动效源码（已在浏览器通过多个章节绘制检查），`preview.html` 是可拖动播放器；`EP01_TIMELINE.json` 有 197 镜的草案；4 份 huashu JSON 采用官方 y3_whiteboard 语法；`build_composition.py` 处理真实 MP4 注入。

不要在用户没有配音/素材时假装导出了最终 20min 成片。时间轴目前是口播字符分配出来的 **rough cut**，最终必须由实际合成/真人音轨生成词时码重排。

## 你的执行顺序（每一步都产出可验收文件）

**M1 技术验证**
- `npm install && python3 scripts/validate.py`。
- 使用 `npx hyperframes lint` / `check`，按当前版本处理 GSAP onUpdate 与 Canvas 逐帧 seek；检查 0/10/80/300/550/790/1020/1180 秒的无黑屏渲染。
- 验证 `preview.html` 与 HF render 在相同时间采样的像素趋势一致；不得使用 wall clock 与非确定性随机。

**M2 花叔实集成**
- `git clone https://github.com/alchaincyf/huashu-art-motion.git third_party/huashu-art-motion`。
- 阅读其 `SKILL.md`、`references/09-视频动画语法.md`、`references/动画语法/y3_whiteboard.md`。
- `bash scripts/render_huashu.sh`，如校验失败，请修正本项目的 4 个 JSON 到仓库当前版本支持的字段（不是修改用户要的历史内容）。
- `python3 scripts/build_composition.py`；验证实际视频插入位置与持续时间。
- 允许后续加入 `y2_vox`，但必须先有来源明确的真实档案图（否则不要为了贴“假档案”而拼图）。

**M3 先做 60s 专业样片**
- 片头 15s：1921/1927/1929/1935 年份串联、金色路径描画。
- 历史背景 15s：节点与时间轴拉远，不要大字 PPT。
- 事件 15s：资料框切换到历史问题图解；内容结构明确标注示意。
- 解释 15s：Huashu 白板推导；真正的箭头/笔画在说话节奏上写出。
- 输出 `output/EP01_60s_preview.mp4`，审阅并修正后再做长片。

**M4 全片高质量版**
- 口播稿事实审稿、找真实权威出处；重要历史材料用于证据镜，优先馆藏和官方授权。
- 使用真人或经授权自有 TTS 配音；依据 **音频真实时码** 重新分配 197 镜，不强凑 1200 秒。
- 让每段都是画面事件（主体线条在生长、事件脉络在展开、路线在移动、论点在推导），每 2–8 秒做一次有意义的构图或信息变化；不平均匀速 zoom。
- 音频 ducking、字幕安全区、最终混音、人眼看完成片。
- 分章输出 + FFmpeg 合并；检查日期、名字、地图示意、镜头重复度、素材许可、文字遮挡。

## 验收硬门

- 静态插画不得成为整片主体。任何真实史料图必须有来源，示意动画必须明确区分。
- 无演示项目中自有素材未经授权的直接复制。
- 100% 的镜头有具体“物+动作”；禁止空背景和纯翻页。
- 节奏和讲述配对，发生在历史中的原词/地点不凭空杜撰。
- 最后真正完成 `HyperFrames render` 的视频才能称为“完成版”。
