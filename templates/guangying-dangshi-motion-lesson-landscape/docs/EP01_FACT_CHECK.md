# EP01 史实核查记录

**核查对象：** [content/EP01_SCRIPT.md](../content/EP01_SCRIPT.md)  
**核查日期：** 2026-10-14  
**范围：** 脚本所述 1900 年前后至 1935 年的历史背景、事件、会议与片尾概括。优先采用中共中央党史和文献研究院、共产党员网、政府档案/纪念机构等来源。此记录核查史实与措辞，不作图片、视频或文献复制的法律判断。

## 核查结论摘要

脚本的主线和主要日期、地点、会议内容总体有官方党史或档案研究来源支持。定稿前建议优先处理以下几点：

1. S04 的“出席中共一大的中国代表共13人”统计口径需要区分：档案考证认为正式代表为12人，包惠僧受陈独秀指派参会；若按中国参会者统计，可说共13人。
2. S04 画面中的一大纲领文献须标出实际版本。现存中央档案馆所藏相关纲领是俄文打印译本；另有陈公博论文所附英译本。现有资料不支持将它们称作会议现场使用的中文原件。
3. S05 把秋收起义后的转移压缩为“1927年9月……向井冈山方向转移”易让人误以为当月即抵达井冈山。建议按“文家市转向—三湾改编—10月抵达井冈山”交代先后。
4. S07 的“作出相应的组织调整”宜拆分会议决定与会后调整，以免把后来分工变化都写成遵义会议当场决定。
5. S06 中“不能仅凭军事技能或个人威望来维持队伍”属于当代解释性说法，不是核查到的古田会议决议原意表述；建议改用决议中可核对的思想教育、党的组织、政治工作等内容。

“支持”表示所述事实有列出的官方来源支持；“需改措辞”表示事实大意成立，但当前简写可能引起误解；“缺素材来源”表示脚本拟用的具体图像/文献尚无逐件来源记录。历史事件来源不等于相应素材可以直接用于视频。
