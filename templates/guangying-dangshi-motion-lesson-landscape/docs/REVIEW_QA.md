# 审核与验收（先质量，后产量）

## 历史事实
- 逐段依据 `content/SOURCES.md` 核对日期、事件、人物与顺序；存在争议的事件采用权威表述并说明语境。
- “嘉兴南湖纪念船”不得称“1921 原船实拍”；会议会址现状图不等于会场原片。
- 结构示意必须标注“图解 / 非历史原始史料”；抽象路线标注“示意 / 非精确行军路线”。
- 拒绝伪造会议细节、领导人真实语音、未证实的直接引语和 AI 伪新闻镜头。

## 视觉与动画
- 在 0、10、80、270、490、735、955、1125、1190s 抽样截图，检查过渡空屏、断点、层遮挡。
- 逐个检验 8 种动态图的至少 0%、50%、100% 状态。中间态必须真的在绘制，非两张图淡化。
- 检查字幕的阅读速度、对比度、安全区和历史地名不出现错别字。
- 在各章中，连续使用同模板次数多于 3 镜应重新设计镜头，避免动画版 PPT。
- 抽样每分钟听 10 秒是否与视觉关键词同步；最终以音轨时间为主。

## 工程
```bash
python3 scripts/validate.py
npx hyperframes lint
npx hyperframes check
# 局部小样 → 每章 → 长片
```
Huashu 成片可追加 `uv run third_party/huashu-art-motion/scripts/qa.py --spec ... --out ...` 等工具，命令以拉取当时仓库帮助为准；通过后将审片记录写进 `output/QA.md`。
