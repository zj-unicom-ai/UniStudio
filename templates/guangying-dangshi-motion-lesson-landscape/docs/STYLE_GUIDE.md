# 统一视觉与动态规范 · 红色档案纪录片

## 色彩（不得引入蓝紫霓虹）

| 元素 | 色号 | 用法 |
|---|---|---|
| 主墨黑 | `#181516` | 主背景、章节底色 |
| 深红 | `#842D34` | 关键年份、线索、重点节点 |
| 朱砂红 | `#A94542` | 运动焦点、路线头 |
| 古铜金 | `#C5A677` | 年代轴、人物关系连接线 |
| 档案米白 | `#E9DFCA` | 解释图纸面、片头字 |
| 次级暖灰 | `#AD9E8D` | 说明、非重点信息 |

字体：优先 `Noto Serif CJK SC` / `Noto Sans CJK SC`，系统缺失时回落 Songti/PingFang。不要打包商用授权不明的字体文件。

画幅：1920×1080 @25fps；四边安全范围≥80px；字幕推荐距底约145px；视频片头不用页码框式 PPT。

## 已实现的代码动效

| 模板 | 具体物件 | 每帧变化 | 适用 |
|---|---|---|---|
| hero | 年份球、连接线、标题 | 年份逐一揭示，线条按长度描绘 | 开场 |
| timeline | 历史节点、金线 | 节点按事件先后出现，路径被描出 | 历史背景 |
| route | 抽象地形线、关键地点、方向路线 | 示例路径逐点写出、节点聚焦 | 道路探索，不精确行军路线 |
| archive | 纸张结构、标题与四段要点 | 模拟纸张进场，信息结构展开 | 历史背景分解，非史料原文 |
| network | 目标/组织/制度/反馈四节点 | 连线依次生长、节点逐次浮现 | 古田会议等组织建设内容 |
| whiteboard | 四步逻辑板 | 逐框书写、箭头连接 | 事件成因/结果解释 |
| contrast | 历史问题、实践回应 | 两侧信息发生对照变化 | 关键转折 |
| recap | 四个年代及联系 | 连接线汇聚、意义句出现 | 收束 |

## 动效规则

- 单个动效 0.25–1.8s；正式 `huashu` 白板镜建议 4–8s。
- 轻缓的路径描绘和节点揭示是主节奏；重大历史转折偶尔使用更快的红线指向，**不允许每镜都做同一种匀速 zoom**。
- 主体必须有具体东西在变化，不要只有背景和一句居中大字。
- 一镜不呈现超过 3 处同时运动的独立焦点；先陈列问题，再展开过程，再标注重点。
- 语义引导清晰：组织建设用关系节点，历史转移用路线，但不能把“象征性路径”当成真实行军路线。
- Huashu 建议用 `y3_whiteboard` 讲因果与组织；`y2_vox` **仅在拿到真实档案/图片并获授权后**使用；`y5_kinetic_type` 只用于片头/年份重音，不用于整个课程。
- 不用 AI 合成视频冒充真实会议录像、历史人物原声或原始档案。
