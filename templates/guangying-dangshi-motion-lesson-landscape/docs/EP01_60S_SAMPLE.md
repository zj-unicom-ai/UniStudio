# EP01 · 60 秒样片说明

这是一支无旁白、无音乐的视觉样片，用来确认叙事节奏、画面层级和双引擎衔接。各段暂按 15 秒划分，后续要依据定稿口播和录音重新校准时码。

HyperFrames 源文件：`compositions/EP01_60s_preview.html`。渲染输出：`output/EP01_60s_preview.mp4`。

| 时段 | 画面任务 |
|---|---|
| 00–15 秒 | 以 1921、1927、1929、1935 四个节点和一条赤金线开场。 |
| 15–30 秒 | 展开 1911、1919、1921、1927、1929、1935 的历史时间线。 |
| 30–45 秒 | 用信息图解释遵义会议背景与议题；注明“结构示意 · 非原始史料”。 |
| 45–60 秒 | 先播放 8 秒遵义议题白板，再接 7 秒白板总结；画面持续标注“图解动画 · 非原始史料”，以“从现实问题到行动调整”收束。 |

史实依据见 [SOURCES.md](../content/SOURCES.md)：R01 覆盖时代背景与历史时间线，R09 覆盖遵义会议日期、议题与后续调整。图解用于说明内容关系，不代表档案或历史现场原貌。
