# AI 单条资讯数字人解读

这个包同时包含 Skill 和可运行的 HyperFrames 工程。整包下载或安装后，可直接检查与渲染随包样片；无需分享者电脑上的项目路径、VoiceStudio、声线 ID 或 MuseTalk 模型。样例数字人视频、示例 WAV、品牌画面和字体均随工程提供。

## 制作流程

1. 阅读 README.md、USAGE.md、TOOLS.md 和 SOURCES.md。收集一条新闻的原始资料、日期、官方来源、必要的第三方评测及用户立场。把事实、厂商说法、第三方测试与个人解读区分开；不确定信息写明口径和时间。
2. 确定本 Skill 安装目录（即本 SKILL.md 所在目录），从该目录调用 scripts/new_project.py 创建工程；不要依赖当前工作目录或作者电脑上的绝对路径。目标路径需不存在，例如 /path/to/new-project。命令拒绝覆盖已存在目录，并排除转码缓存和渲染产物。需要生成新内容时在新工程内工作。
3. 编辑 data/sample-episode.json 与 voice-requests.json，按 USAGE.md 保持 intro、每个正文页和 outro 的旁白段 ID 一一对应。更新 SOURCES.md，引用可追溯来源。正文页数可按内容调整。
4. 检查示例声线是否可用。生成脚本默认请求本机 VoiceStudio；先把 `voice-requests.json` 中的 `voice` 改成当前服务中自己获准使用的声线 ID。可用 VOICE_API_URL 指定 OpenAI 兼容接口，并按服务要求设置可选 VOICE_API_KEY，或提供 24 kHz、单声道、16-bit PCM WAV。不要假定样例声线可被其他使用者调用。
5. 只运行随包样例时不需要 VoiceStudio 或 MuseTalk。替换旁白后，先生成开场、每页和结尾全部 WAV，再运行 npm run build 与 npm run check。按自己的形象重新生成数字人口型还需要 MuseTalk v1.5、模型权重、FFmpeg、正面人物素材和匹配遮罩；否则保留随包样例口型，不声称它与新旁白同步。
6. 运行 npm run dev 预览。检查数字人只在封面开场、正文标题在上一页退场后再出现并与旁白同步、翻页音效、来源行和六秒固定片尾。开场第 0 帧是有意设计的暗场，完整封面取视频约 2 秒处，确保标题和人物都已出现。
7. 运行 npm run render -- --quality high --output out/<name>.mp4。命令同时生成完整首页封面 PNG 与带 poster 的播放页 HTML。核对 MP4 为 1080×1920 / 30 fps，检查封面、正文、片尾、音画同步与最终帧。
8. 交付 MP4、单独封面 PNG、播放页和源工程路径。标明新配音及口型分别使用了什么条件。用户若只要求工程或样例渲染，明确说明其音轨和数字人仍是示例内容。

## 固定版式与边界

- 叙事单位是一条新闻的深度拆解：封面数字人口播开场，正文使用 5 页左右的信息结构，结尾复用固定品牌片尾。不要把它改成多条快讯合集。
- 保留深蓝地球底图、标题遮罩进场、星圈和滑光、正文统计卡/观察页及系列片尾。使用自有人物或替换声音时，确认人物图、声音、品牌标识与音效都获准用于该项目。
- 时间轴按 WAV 实测时长生成。替换配音后必须重建 timing 与 index；不得靠估算时长或随机动效实现音画同步。
- 随包示例人物、声音、Logo、音效与第三方数据图文可能有独立权利。仓库 MIT 只覆盖模板代码；发布前核对 SOURCES.md 与 TOOLS.md 所列授权范围。

字段、脚本、端口和音频规格见 USAGE.md；环境和素材说明见 TOOLS.md。
